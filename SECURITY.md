# Security reporting

Do not post vulnerability details, credentials or personal data in public issues or pull requests.

Report privately through GitHub's private vulnerability reporting for this repository: [open a report](https://github.com/PaigeRattenberry/stimmap3d/security/advisories/new), or use the Report a vulnerability button on the repository's Security tab. Include the affected version, impact and a minimal reproduction. Reports are read by the sole maintainer; no response-time commitment is asserted here.

The supported target is the current main branch with Node 24. Dependency review includes the application and both authoring roots. This educational app does not accept real patient information.
