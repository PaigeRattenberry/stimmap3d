# Security reporting

Do not post vulnerability details, credentials or personal data in public issues or pull requests. A private reporting channel must be enabled and verified on the selected hosting repository before accepting security reports. No monitored email address or response-time commitment is asserted here.

When available, use the repository Security tab's private reporting form with the affected version, impact and a minimal reproduction. If unavailable, request a private channel without disclosing vulnerability details and wait for the maintainer's response.

The supported target is the current main branch with Node 24. Dependency review includes the application and both authoring roots. This educational app does not accept real patient information.
